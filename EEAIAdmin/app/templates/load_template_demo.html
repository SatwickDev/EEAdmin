Load Template Sample Button - Implementation

New Feature Added

A "Load Template Sample" button has been added to the LC form that allows users to quickly populate the form with sample data for testing and demonstration purposes.

What Was Implemented

1
Button Added to Form
Added a new "Load Template Sample" button to the LC form button group with an attractive info-style design.
2
CSS Styling
Created new .btn-info CSS class with a gradient blue background and hover effects.
3
JavaScript Function
Implemented loadTemplateSample() function that fetches sample data and populates all form fields.
4
Backend Enhancement
Enhanced the existing route to return JSON data when load_template=true parameter is passed.

Button Implementation

HTML Button:

<button type="button" class="btn btn-info" onclick="loadTemplateSample()"> <i class="fas fa-file-import"></i> Load Template Sample </button>

CSS Styling:

.btn-info { background: linear-gradient(135deg, #0ea5e9 0%, #0284c7 100%); color: white; border: none; box-shadow: var(--shadow-sm); } .btn-info:hover { background: linear-gradient(135deg, #0284c7 0%, #0369a1 100%); transform: translateY(-1px); box-shadow: var(--shadow); }

How It Works

1
User clicks "Load Template Sample" button on the LC form
2
JavaScript makes an AJAX request to /trade_finance_lc_form?load_template=true
3
Backend returns sample LC data in JSON format
4
JavaScript populates all form fields with the sample data
5
User sees success message and can review/modify the populated data

Sample Data Included

  • ✓ LC Number (auto-generated with timestamp)
  • ✓ Applicant and Beneficiary details
  • ✓ Banking information (Issuing & Advising banks)
  • ✓ Amount, Currency, and Payment terms
  • ✓ Shipment details and dates
  • ✓ Goods description and specifications
  • ✓ Document requirements (checkboxes)
  • ✓ Additional conditions and terms
