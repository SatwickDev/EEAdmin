LC Success Page Implementation Demo

This demonstrates the new Letter of Credit submission success page with SWIFT preview functionality.

New Routes Added

LC Success Page:
http://127.0.0.1:5002/lc_success?lcNumber=LC20251010123456&transactionId=ABC123
Guarantee Success Page:
http://127.0.0.1:5002/guarantee_success?guaranteeNumber=BG20251010123456&transactionId=DEF456
SWIFT Preview API:
POST http://127.0.0.1:5002/api/lc/swift-preview-form

User Flow

1
User fills out LC form at /trade_finance_lc_form
2
User clicks "Submit LC" - form shows loading state
3
API processes submission via /api/lc/submit
4
Form data stored in sessionStorage for SWIFT preview
5
Browser redirects to success page with LC details
6
Success page shows transaction details and "View SWIFT Preview" button
7
User clicks SWIFT preview - modal opens with generated MT700 message
